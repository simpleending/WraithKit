Two lead Wraiths.

Two apps to start with, built on the same Rust kernel. Each has its own tools and demo.

Security Wraith

Investigate first.
Act with permission.

Review an incident and its response plan.

Import redacted 1-SEC events and alerts, inspect the evidence, then approve a local response plan. The demo also lets you approve a simulated pause and its reversal separately.

The importer does not connect to 1-SEC or redact secrets for you. Plans made from imported evidence are saved locally, never carried out on a real system.

Release Wraith

Find the mismatch.
Review the repair.

Check a release plan against the artifact that actually exists.

Find a wrong artifact path in a release plan. Check the local file’s hash and approve the exact correction.

Checks local files only. It does not rerun CI, build or publish a release.

    Bring your first
    Wraith to life.

    From your local checkout, use Rust 1.96 or newer. Build once, then run either scripted demo with no model key. The first build may download dependencies.

    >_From the WraithKit checkoutScripted / local
    1. cargo build --workspace --locked
    2. cargo run --locked --offline -p security-wraith -- demo
    3. cargo run --locked --offline -p release-wraith -- demo

    What happens next

    Open the local URL printed in your terminal. You can read the evidence and proposed file change, then approve or deny it.

    Security asks separately before reversing its simulated pause. Release checks the plan again after your decision. Choose Verify ledger to check the recorded run.

    These demos use scripted replies and sample data. Approvals and file changes run for real. For your own data, input formats and optional model setup are in each app’s README. Live mode sends task and tool data to your configured provider.

    Run the bonus examples
    1. cargo run --locked --offline -p repo-wraith -- demo
    2. cargo run --locked --offline -p research-wraith -- demo

    Local preview. The source repository is linked above. Read README.md for setup and limits, and BUILD_LOG.md for the Kiro and later ChatGPT-assisted work. This toolkit runs trusted local apps, not a sandbox.
