- **2026-11-16, Kiro IDE (Claude Opus 5.5), final senior pass (bugs, crash safety, races, security):**
  - Method: I read all production code. An independent reviewer read it a second time with no shared context and confirmed two of its findings with throwaway crates outside the repo. Every fix below has a test. Each test was run with its fix removed and failed (exit 101), then passed again after the restore.
  - Data integrity and crash safety:
    - A crash mid-write could leave a partial blob under its final name, and a later identical `put_blob` trusted it. Blobs are now written to a temp file and renamed, and an existing blob is reused only if its hash matches. Test: `blob_replaces_partial_file`.
    - A crash after a decision and before its tool result (deny, stale, or effect done) left a call with no tool message, so every live resume failed with HTTP 400. Resume now answers with the recorded outcome: the denial, the stale reason, or the receipt. It never says "not run" about an effect that ran.
